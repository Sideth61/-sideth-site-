DSN OS: System Architecture & Integration Guide

1. System Overview

DSN OS is designed as a Progressive Web Application (PWA) to provide a desktop-like environment within the browser. It integrates with native device storage and cloud services (Google Drive/iCloud) via the File System Access API and Storage API[span_0](start_span)[span_0](end_span).

2. System Components

Module Description
Kernel (Core) Handles resource management, state persistence, and inter-app communication[span_1](start_span)[span_1](end_span).
Filesystem (VFS) Virtual File System that maps to localStorage (for web) and FileSystemHandle (for local/cloud integration)[span_2](start_span)[span_2](end_span).
Display Engine Manages theme states (Brightness/Contrast/Dark Mode) via CSS Custom Properties[span_3](start_span)[span_3](end_span).
App Store Manages installation of web-based micro-apps into the VFS[span_4](start_span)[span_4](end_span).
